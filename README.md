# JavaScript-Advanced-Practice
Exercises to deepen the understanding of problem-solving logic in JavaScript

## About this repository
Well, this repository contains exercises that made me think a lot more (and frustrated me a lot more too).
Some may seem easy, but for someone who, at that point had only been learning code for two weeks, they were literally brain teasers.
Some still are, and I feel that even though I understand the answer, I still can't come up with that line of thinking on my own. Instead, I need assistance or someone to guide me step by step to “find the right clues.”
In any case, I'm proud to have been able to complete them, with or without help. That's what coding is all about: constant learning and, let's face it, it's an uphill battle!
